## Human Duration

This package gives functions to convert a duration in milliseconds to usable and human readable formats.

### Long Full Notation
writes all out in text

### Long Valuable Notation
writes all out in text, except 0 values

### Short Full Notation
writes all out in abbreviations

### Short Valuable Notation
writes all out in abbreviations, except 0 values

### Time Full Notation
writes all out in a very compact time notation

### Time Valuable Notation
writes all out in a very compact time notation, but no days if 0
